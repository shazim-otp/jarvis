# Why I Made This Project

I made Meck AI because I have always been interested in futuristic AI assistants like Jarvis. I wanted to create something that felt real — an assistant that could listen, speak naturally, remember conversations, and interact like a human companion instead of just being a simple chatbot.

Another reason was hardware limitations. Most advanced AI assistants require expensive GPUs and powerful systems, but I only had an Intel i3 laptop with 4GB RAM and integrated graphics. I wanted to challenge myself to build a fast and useful AI assistant that could still work smoothly on low-end hardware using optimized tools and cloud AI inference.

I also noticed that most voice assistants do not properly support Malayalam or Manglish conversations. Since I speak both English and Malayalam daily, I wanted to create an assistant that could naturally understand and reply in both languages.

This project helped me explore:
- Real-time speech recognition
- AI API integration
- Voice synthesis
- Multilingual conversational AI
- Audio processing
- Wake-word systems
- Interrupt-driven interactions

The goal of Meck AI is to become a lightweight but powerful personal assistant that can eventually integrate with robotics, home automation, IoT devices, and smart systems in the future.
